# Академия Финтеха Муси-пуси

ВТБ Смарт-сделка — сервис для самозанятых и их клиентов: бриф, этапы работы, материалы, согласование условий и график оплаты.

Сайт: https://musi-pusi.avotaangi.ru/

## Запуск

Требуется Node.js 20 или новее.

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm test
npm run build
npm start
```

## Возможности

- Кабинеты исполнителя и клиента, приглашения по ссылке и QR-коду.
- Собственные брифы и этапы, параллельные работы, сроки и график платежей.
- Материалы, приёмка, доработка и спор.
- Согласование изменений условий с сохранением истории.
- Редактируемые названия сделок, календарь и уведомления.
- Мобильная и компьютерная версии.

## Текущая реализация

Данные сохраняются в браузере: сделки в localStorage, файлы в IndexedDB. Переключение кабинетов не является серверной авторизацией. Оплата, резерв и выплата моделируются без движения реальных денег. Для банковского пилота требуются серверное хранение, авторизация и интеграция расчётов.

Стек: React 18, Vite, CSS, Lucide, QRCode. Шрифт хранится локально.
